# Leo en el Tiempo

Plataforma educativa e interactiva para explorar la historia de Colombia en el Siglo XX junto a Leo el León Explorador Temporal.

## Características
- Misiones temporales interactivas
- Minijuegos educativos (Trivia, Crucigramas, Ordenar sucesos)
- Museo y Galería de héroes y personajes históricos
- Asistente de voz cuántico "Oye Leo"
- Pasaporte temporal y racha de exploración

Desarrollado con React 19, TypeScript, Tailwind CSS y Vite.
